## 二、什么是 Codex？

Codex 是 OpenAI 官方出品的 AI 编码工具，能理解你的需求，帮你写代码、跑命令、调 Bug。

它现在常见有四种运行模式：

这四种模式没有谁绝对更强，核心还是看你平时的工作流。

## 五、如何安装 Codex？

Codex 的安装不复杂，基本就是：装环境、装客户端、登录、跑起来。

### 1. 环境要求

先装 Node.js 和 Git：

```bash
node --version
npm --version
git --version
```

如果没装，先补上。

### 2. 安装 CLI

```bash
npm install -g @openai/codex
```

验证安装：

```bash
codex --version
```

### 3. 安装 App

Windows 用户可以直接装桌面端，图形界面更省心。

### 4. 云端版

如果你有 GitHub 仓库，也可以直接走云端版。

### 5. IDE 插件

VS Code、Cursor、Windsurf 都能接：

```text
https://developers.openai.com/codex/ide
```

## 六、在 CLI 端使用 Codex

CLI 是 Codex 最像开发者工具的形态：你在终端里提需求，它在项目里改文件、跑命令、修问题。

### 1. 启动

```bash
codex
```

### 2. 登录

如果你是 ChatGPT Plus 用户，可以直接授权登录。

也可以选择 API Key 方式：

```bash
platform.openai.com
```

### 3. 试一个最小任务

先别上来就重构祖传系统，先试点小任务更稳：

```bash
cd d:\test\
codex "用 Python 写一个贪吃蛇的游戏"
```

你负责描述目标，它负责拆任务、改文件、跑命令。

### 4. 常用命令

```bash
codex logout
codex login
/model
```

## 八、在云端使用 Codex

云端版适合已经放到 GitHub 上的项目。你可以把它理解成：本地 Codex 在你电脑上干活，云端 Codex 连到你的 GitHub 仓库里干活。

### 1. 初始化 Git 仓库

```bash
git init
```

### 2. 创建 GitHub 远程仓库

把项目推上 GitHub 后，再连到 Codex。

### 3. 连接 Codex 到 GitHub

打开云端页面，连接仓库，授权之后就能让它看项目。

这一步很适合先做测试：先问它“这是个什么项目”，别一上来就让它重构整个系统。

## 九、IDE 端使用 Codex

IDE 插件适合日常写代码的人。它最大的价值不是再开一个聊天窗口，而是直接读取当前项目上下文，在你写代码的位置帮你改。

你可以先从这几个场景开始：

- 让它解释当前文件的作用
- 选中一段代码，让它重构或补注释
- 把报错信息贴进去，让它定位问题
- 让它给某个函数补单元测试

IDE 插件适合边写边问，CLI 适合直接派活。

## 十、进阶用法

### 1. AGENTS.md

在项目根目录创建一个 `AGENTS.md`，告诉 Codex 你的项目规范。这个文件相当于项目说明书。

```md
# 项目规范
- 语言：Python 3.11+
- 代码风格：PEP 8
- 测试框架：pytest
- 注释：中文注释
```

### 2. 常用场景

Codex 不只是写代码，还能做：

- 代码重构
- 写单元测试
- 修复 Bug
- 代码审查

### 3. 安全模式

新手推荐先开“自动审查”模式：日常能自动改，关键操作会问你。不要一开始就完全放权。

### 4. 接入国内大模型

如果你想让 Codex 接国内模型，也可以改配置。

但要注意，OpenAI 兼容不等于 Codex 一定可用。它更依赖 Responses API，只有部分平台适配得比较完整。

这时如果你想少折腾，可以把 endpoint 统一成 [Code80](https://code.ai80.vip/home) 这样的入口，少掉一层支付和网络处理。

## 十一、常见问题

### 1. 登录失败怎么办？

先检查网络，再清浏览器缓存，再试 `codex logout` / `codex login`。

### 2. `codex` 命令找不到怎么办？

检查 Node.js、npm 的全局路径和 PATH 环境变量。

### 3. 配了环境变量还是不生效？

重启 Codex，必要时重启电脑。

### 4. 国内用户怎么更省事地接上官方 API？

可以直接把入口统一到 [Code80](https://code.ai80.vip/home)。

### 5. 新手最适合从哪开始？

先从 CLI 或 App 选一个跑通，再补 IDE 插件。

### 6. 第一单任务应该做什么？

修一个报错、补注释、写测试、改一个小脚本，别一上来就搞大重构。
